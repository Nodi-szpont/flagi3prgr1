# Flagi

Aplikacja zawierająca flagi Polski i innych krajów - quiz do rozpoznawania flag.

## Nauczasz się:
- **TextView** - wyświetlanie tekstu i komunikatów
- **Toast** - wyskakujące powiadomienia
- **Obsługa kliknięć** - listener onClick()
- **Liczniki** - śledzenie ilości poprawnych odpowiedzi
- **Widoczność elementów** - setVisibility(View.INVISIBLE)
- **Warunki** - logika sprawdzania poprawnych odpowiedzi
